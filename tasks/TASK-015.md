## 概要

Gmailに届いた問い合わせメールをClaude APIで「クレーム/質問/注文/その他」に自動分類し、
スプレッドシートに記録してSlackに通知するツールをGASで作る。
5分おきに自動実行されるトリガーも設定する。

## 手順サマリー

1. スプレッドシートを準備する（「メールログ」「エラーログ」の2シート）
2. Claude APIキーを取得・スクリプトプロパティに登録する
3. Slack Incoming Webhook URLを取得・スクリプトプロパティに登録する
4. Claude Code に `email_classifier.gs` の生成を指示する
5. GASエディタでコード実行・動作確認する
6. トリガー設定関数を実行して5分おき自動実行を完成させる

## 事前準備

### スプレッドシートのシート構成
- 「メールログ」シート: `受信日時 | 送信者 | 件名 | 分類 | 要約`
- 「エラーログ」シート: 空のまま（エラー発生時にGASが書き込む）

### スクリプトプロパティに登録するキー
| プロパティ名 | 内容 |
|---|---|
| `CLAUDE_API_KEY` | Anthropicで発行したAPIキー（キー名の例: gas-scripts） |
| `SLACK_WEBHOOK_URL` | Slack Incoming Webhook URL |

## Claude Codeへの指示プロンプト（コピー用）

```
`email_classifier.gs`というファイルを作成し、以下のGASスクリプトを実装してください。

処理の流れ：
1. Gmailで「要処理」ラベルがついた未読メールを取得する
2. メール本文をClaude APIに送り「クレーム」「質問」「注文」「その他」に分類してもらう
3. 受信日時・送信者・件名・分類・要約の順にスプレッドシートの「メールログ」シートに記録する
4. Slack Incoming Webhookで担当者に通知する（件名・分類・要約を含める）
5. 処理済みのメールに「処理済み」ラベルをつけて「要処理」ラベルを外す

実装の要件：
- APIキーはスクリプトプロパティから取得する（CLAUDE_API_KEY・SLACK_WEBHOOK_URL）
- エラーが発生した場合は、エラーの内容をスプレッドシートの「エラーログ」シートに記録する
- Claude APIはclaude-haikuの最新バージョンを使用する（コストを抑えるため）
- 5分おきに実行されるトリガーを設定する関数も含める
- コメントは日本語で記載する
```

- APIキーはコードに直書きせず、必ずスクリプトプロパティから取得すること
