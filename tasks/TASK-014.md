## 概要

Googleスプレッドシートの売上データを自動集計し、月次サマリーと棒グラフを生成するダッシュボードをGASで作る。
毎朝9時に自動実行されるトリガーも設定する。

## 手順サマリー

1. スプレッドシートを準備する（「売上データ」「月次サマリー」の2シート）
2. Claude Code に `summary_dashboard.gs` の生成を指示する
3. GASエディタにコードを貼り付けて実行する
4. トリガー設定関数を実行して自動化を完成させる

## スプレッドシートのデータ構造

**「売上データ」シート**
| 日付 | 担当者 | 商品名 | 金額 |

**「月次サマリー」シート（出力先）**
| 月 | 合計売上 | 件数 |

## Claude Codeへの指示プロンプト（コピー用）

```
`summary_dashboard.gs`というファイルを作成し、以下のGASスクリプトを実装してください。

Googleスプレッドシートの売上データを自動集計して別シートにサマリーを書き込み、月次推移をGoogleチャートで表示します。毎朝9時に自動実行されるトリガーも設定します。

データ構造は以下の通りです。

【「売上データ」シート】
- A列：日付（例：2026/01/05）
- B列：担当者名
- C列：商品名
- D列：金額（数値）

【「月次サマリー」シート（出力先）】
- A列：月（例：2026年1月）
- B列：合計売上
- C列：件数

要件：
- 「売上データ」シートの全行を読み込み、月ごとに集計する
- 「月次サマリー」シートを毎回クリアしてから書き直す
- 同じスプレッドシート内に棒グラフを作成し、月次推移を可視化する
- 毎朝9時の自動実行を登録するための専用関数も作成する（この関数をGASエディタで一度だけ実行すると、以降は毎朝9時に集計処理が自動で走るようになります）
- コメントは日本語で記載する
```
